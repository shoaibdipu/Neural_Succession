# Supplementary code: Neural Succession (Successional Learning Theory)

This archive contains all code used to produce the experimental results, figures, and statistics in the paper, together with the
result records the figures are built from.

## Quick start

    pip install -r requirements.txt
    python analysis/make_figures_and_stats.py      # regenerates figures/ and records/derived/derived_revision_stats.json from records/

`run_all.sh` lists the commands that re-run every experiment. Datasets (MNIST, CIFAR-10, CIFAR-100) are downloaded by torchvision into
`$SLT_DATA` (default `./data`). GPU training is not bitwise deterministic, so re-runs reproduce the reported statistics up to seed-level
variation; the analysis script reproduces every reported number exactly from the shipped records.

## Layout

| Folder | Contents |
|---|---|
| `succession/` | E1-E5 experiment scripts (natural transitions, prospective forecast, coexistence, replay, benchmark) |
| `transition_suite/` | predictor comparison (E6), niche/fitness decomposition (E6), controlled task-relation sweep (E8) |
| `mechanism_suite/` | revalidation, 84-transition coexistence suite, CIFAR-100 scope, microscopic scale tests, stages, robustness |
| `protection_suite/` | resident bank and protection study (Appendix C) |
| `analysis/` | `records_from_logs.py` (turns the E3 v1 / E4 / E5 console tables into records) and `make_figures_and_stats.py` |
| `records/` | the JSON/CSV records written by the experiment scripts and used by the analysis |
| `figures/` | all figures in the paper, as regenerated by the analysis script |
